# ATLAS — desktop installers

ATLAS is a local-first Formula 1 telemetry workstation for Windows. This repository only hosts the installers: the download lives under [Releases](https://github.com/matiennn33/atlas-releases/releases/latest), and the product page is [atlasf1.app](https://atlasf1.app).

## Install

1. Download `ATLAS-Setup-<version>.exe` from the latest release.
2. Run it and follow the setup.
3. If Windows SmartScreen stops the installer, choose **More info**, then **Run anyway** — the installer is not yet signed with a paid publisher certificate.

Requires Windows 10 or 11, 64-bit. Each release lists the installer's SHA-256 so you can check the download.
